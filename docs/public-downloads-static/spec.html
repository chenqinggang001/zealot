整体视觉方向

现代、简洁、企业级 App 商店风格。以蓝紫系强调色为主色，背景保持白与浅灰中性， 通过卡片层级与字体权重构建清晰的信息层次。不出现侧边栏、管理按钮、后台导航等管理界面元素。

移动端优先：单列布局，大号触控区域。桌面端增强：列表页可切换为 2–3 列 Grid， 详情页二维码与操作按钮左右并列，历史版本完整宽度展示。

响应式

移动端（≤640px）

  • 单列全宽卡片
  • 平台筛选可横向滚动
  • 详情页二维码独占一行居中
  • 安装 / 下载按钮纵向排列
  • 触控目标 ≥ 44px

桌面端（≥768px）

  • 列表可 2–3 列 Grid
  • 详情二维码与按钮左右并列
  • 历史版本四列表格完整展示
  • 内容区最大宽度约 720–960px 居中
